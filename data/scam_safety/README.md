# Scam-safety data

This directory belongs to Nightwatch's original scam-safety model-repair mission.

`fixture.jsonl` is a small, newly authored contract and gate fixture. It exists only to exercise loading, evaluation, and deterministic release behavior. It is not training data, a benchmark, a retained model result, or judge-facing evidence.

Scientific evidence will use separately authored development and sealed evaluation files. Those files must pass exact-overlap checks, preserve target/regression/safety boundaries, record their hashes in mission artifacts, and never be shown to a curriculum-generating agent.
